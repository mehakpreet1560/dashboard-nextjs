This project is a modular and responsive dashboard built using Next.js, TypeScript, and Tailwind CSS. It is designed with a clean and scalable structure that can be extended into CRM systems, analytics dashboards, admin panels, or any type of data-driven application. The architecture follows a component-based approach, making each part of the interface reusable and easy to maintain. The layout is responsive across different screen sizes, and all styling is handled through Tailwind CSS for consistency and efficiency. The project is organized using the Next.js App Router, providing better routing performance and a clear application structure. The source code includes separate components for the sidebar, dashboard header, metrics grid, metric cards, activity stream, recent activity, summary cards, insights section, charts, usage meter, engagement chart, and top playbooks chart. Global styles are defined in a single CSS file, and configuration settings are managed through Tailwind’s configuration file.

To run the project, install the dependencies with npm install, start the development server using npm run dev, build the project for production with npm run build, and start the production version using npm start. The project uses a modern stack that includes Next.js with the App Router, TypeScript for type safety, Tailwind CSS for styling, and custom React components for charts and analytical displays. Deployment is optimized for Vercel, and the project can be deployed by installing the Vercel CLI and running the vercel command, or by connecting the repository directly to Vercel for automated builds.
